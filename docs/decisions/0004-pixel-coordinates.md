# 0004 マップの座標をマップ画像の px で持つ

決めた日: 2026-03-20(マイグレーション V6、V8、V9)
記録を書いた日: 2026-10-17

## 状況

最初の設計では、座標をマップの幅に対する割合(0 から 1)で持っていた。
管理の画面でマップを押して座標を取るようになり、座標の単位を決め直す必要があった。

## 決めたこと

座標と半径を、1024 四方の座標空間の数で持つ。
マップ画像は、この座標空間いっぱいに引き伸ばして描く。
型は `numeric(7,2)` とする。

## 理由

- 管理の画面で押した場所の座標を、そのまま保存できる。割合に直す計算が要らない。
- マップの描画(Konva)が画像の px で描くので、描くときにも変換が要らない。
- マップ画像のファイル(`frontend/public/map/`)は 1000 px 四方である。旧版の画面は画像を 1024 四方に引き伸ばして描き、その上で座標を取ってきた。今ある座標を変えずに使うため、座標空間を 1024 のままにする。

## 却下した案

- **割合(0 から 1)のまま持つ**: 画像の大きさが変わっても値が変わらない。保存と描画のたびに変換が要り、旧版では `DECIMAL(5,4)` が px の値を入れられずに不具合になった。

## 影響

- マップ画像を差し替えるときは、画像を 1024 四方に引き伸ばして描く決まりを守れば、座標を直さずに済む。画像の縦と横の比が変わるときは、すべての座標を直す必要がある。
- 地変の中心の座標(`jihen.center_x`、`center_y`)は旧版で割合のまま残っていた。新しいスキーマでは px に直す([データベースの共通仕様](../design/common-database.md) 5.6)。
