# 0006 ビルドシミュレーターの計算をブラウザで行う

決めた日: 2026-07-05(ビルドシミュレーターを足したコミット `f8a5f0c`)
記録を書いた日: 2026-10-17

## 状況

ビルドシミュレーターは、選んだ効果の合計を、選ぶたびに出し直す。
計算をどこで行うかを決める必要があった。

## 決めたこと

計算はブラウザで行う。
バックエンドは効果のマスタを返すだけにする。

## 理由

- 選ぶたびに API を呼ぶと、通信の待ちが表示に出る。
- 計算に要るのは効果のマスタだけで、データベースの他の行を要らない。
- 結果を保存しないので、バックエンドで計算した値を残す理由がない。

## 却下した案

- **バックエンドに計算の API を置く**: 計算の正本がサーバーの 1 か所になる。選ぶたびに通信が要り、同じ計算を画面に持たせないなら表示が遅れる。

## 影響

- 計算の決まりは `frontend/src/lib/buildCalc.ts` にあり、テストは Vitest で書く。
- 選んだ組み合わせを保存するようになったら、保存する値を画面の計算の結果にするか、バックエンドで計算し直すかを決め直す。
