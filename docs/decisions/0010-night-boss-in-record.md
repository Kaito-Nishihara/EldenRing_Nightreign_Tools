# 0010 記録に夜ボスを持たせ、拠点の種類を持たせない

決めた日: 2026-10-17

## 状況

旧版の記録の画面には、拠点候補地を押して拠点の種類(砦、教会など)を付ける操作があったが、保存していなかった。
夜ボスのマスタ(V10)はあったが、記録から参照していなかった。
記録に何を足すかを決める必要があった。

## 決めたこと

記録に、1 日目と 2 日目の夜ボスを任意の項目として持たせる。
拠点の種類は保存せず、記録の画面から拠点の種類を付ける操作と、拠点候補地の表示を外す。

## 理由

- 利用者が選んだ。
- 夜ボスは選択の欄 2 つで入れられ、後から収縮との関係を調べる材料になる。
- 拠点の種類は 1 回のプレイで十数か所あり、プレイ中に入れる数が多い。保存しない操作を残すと、保存されると誤解させる。

## 却下した案

- **夜ボスと拠点の種類の両方を持たせる**: 記録が詳しくなる。プレイ中の入力が多くなり、記録の数が集まりにくくなる。
- **夜ボスをパターン検索の条件に入れる**: 夜ボスの違う記録を分けて見られる。条件の組が増えて、1 つの条件の記録が少なくなる。

## 影響

- `play_records` に `day1_night_boss_id` と `day2_night_boss_id` を足す。どちらも `NULL` を許す。
- 夜ボスはパターン検索の条件にも出力にも入れない。パターンのカードに夜ボスを出すかは、記録が集まってから決める([パターン検索](../design/pattern-search.md) の未決事項)。
- 夜ボスを記録から参照するので、夜ボスのマスタを消せない。夜ボスはマイグレーションの初期データで管理し、管理の画面では編集しない。
- 拠点候補地は、マスタの管理の画面でだけ扱う。
