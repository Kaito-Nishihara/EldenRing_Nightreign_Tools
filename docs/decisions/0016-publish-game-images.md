# 0016 ゲームの画像を公開の場で使う

決めた日: 2026-10-18

## 状況

マップ画像と開始地点、拠点のアイコンは、旧版から `frontend/public` にあり、画面と仕様書の画面の試作が使っている。
これらを公開の場で使ってよいかは、要件定義 12 章の未決事項で「公開の前」に決めることになっていた。
仕様書のサイトを GitHub Pages で公開するにあたり、サイトにこれらの画像を載せるかを決める必要があった。

## 決めたこと

マップ、ボス、拠点の画像を、公開する仕様書のサイトとアプリで使う。

## 理由

- 利用者が、使ってよいと判断した。
- 画像を外すと、画面の試作のマップが座標の点と線だけになり、試作で収縮の位置を確かめられない。
- リポジトリは公開しており、画像はすでに `frontend/public` で誰でも取れる。

## 却下した案

- **画像を外してサイトを公開し、権利が決まってから載せる**: 公開の場に出す範囲は狭くなる。試作のマップが読みにくくなり、いつ載せるかの決め手もない。

## 影響

- 要件定義 12 章の未決事項「マップ画像の権利」を閉じた。
- 仕様書のサイトは、画面の試作が使う画像を含めて公開する。
- 権利者から求めがあったときは、サイトとアプリから画像を外し、この決定を見直す。
