# 0018 拠点候補地を大拠点、小拠点、強敵に分ける

決めた日: 2026-10-21

## 状況

拠点候補地は、通常のマップに 15 か所だけあり、種類を持っていなかった(決定の記録 [0010](0010-night-boss-in-record.md))。
攻略 wiki の「地図と拠点の詳細」の地図では、拠点の場所が赤(大拠点)と青(小拠点)の丸で分けて描かれている。
同じ wiki の「フィールドボス」の地図には、強敵(フィールドボス)の出る場所が描かれている。
フィールドボスの出る場所は決まっていて、出るボスは毎回変わると書かれている。
拠点候補地とフィールドボスの場所を、どう持つかを決める必要があった(#130、#46)。

## 決めたこと

拠点候補地に、大拠点、小拠点、強敵の 3 つの種類を持たせ、強敵の出る場所も拠点候補地の行として持つ。

## 理由

- 利用者が決めた。
- 赤と青の区別は場所ごとに決まっている。毎回変わるのは、その場所に出る施設(小砦、大教会など)である。場所ごとの区別は、マスタに持てる。
- 強敵の出る場所は決まっていて、ボスは毎回変わる。名前と座標だけを持つ点で、拠点候補地と同じ形になる。
- 1 つのテーブルの列を 1 つ足すだけなので、`master-service` の場所の管理の部品と、管理の画面の操作をそのまま使える。

## 却下した案

- **フィールドボスを別のテーブルで持ち、名前に出るボスの名前を入れる**: 出るボスが毎回変わるので、場所にボスの名前を結び付けられない。テーブルと API と管理の画面の種類が 1 つずつ増える。
- **赤と青を分けずに、強敵だけを足す**: 参考にした地図の区別を捨てることになる。利用者が分けると決めた。

## 影響

- `base_points` に、種類の列 `kind` を足す。値は `major`(大拠点)、`minor`(小拠点)、`field_boss`(強敵)の 3 つである。
- 通常のマップの初期データを、wiki の地図から取った座標に直し、37 か所にする。今の 15 か所は、どれも大拠点の丸に重なったので、大拠点にする。
- 座標の取り方は、wiki の地図の画像を、手元のマップ画像(`frontend/public/map/Default.webp`)に特徴点で重ね合わせ、丸と印の中心を写すものである。実際のゲームでは確かめていない。ずれていたら、管理の画面で直す。
- 地変のマップの拠点候補地は持たないまま残す。wiki の地図が通常のマップだけのためである。
- 決定の記録 [0010](0010-night-boss-in-record.md) の、記録に拠点の種類(施設の種類)を持たせない決まりは変えない。
- 記録の画面でフィールドボスとレッドボスを選ぶ形は、#46 で決める。
