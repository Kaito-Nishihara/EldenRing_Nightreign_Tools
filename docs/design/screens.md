## 1. パターン検索画面

**URL:** `/`  
**アクセス制限:** なし

### レイアウト

```
┌────────────────────────────────────────────────────┐
│ ヘッダー: タイトル                   [記録入力→]  │
├──────────────┬─────────────────────────────────────┤
│              │                                     │
│ 条件選択     │          マップキャンバス           │
│  ボス        │                                     │
│  地変        │      （収縮候補地・パターン表示）   │
│  開始地点    │                                     │
│              │                                     │
├──────────────┤                                     │
│              │                                     │
│ パターン一覧 │                                     │
│ （検索結果） │                                     │
│              │                                     │
└──────────────┴─────────────────────────────────────┘
※ スマホはサイドパネルがボトムシートに変化
```

### 機能

| 機能 | 詳細 |
|------|------|
| 条件選択 | ボス・地変・開始地点をセレクトボックスで指定 |
| パターン検索 | 条件が揃った時点で自動的にAPIリクエストを送信 |
| パターン一覧 | 記録件数・確率を色分けカードで表示、上から確率順 |
| マップ表示 | 地変に応じたマップ画像に切り替え |
| 収縮候補地表示 | 12ゾーンを円形マーカーで表示 |
| パターン描画 | 選択パターンの収縮円をDay順に線で接続して表示 |
| 収縮エリア暗化 | 選択スロットの収縮円外を暗くオーバーレイ |
| 記録入力遷移 | ヘッダーボタンから `/record` へ遷移 |

### 使用コンポーネント

| コンポーネント | 役割 |
|----------------|------|
| `ConditionPanel` | ボス・地変・開始地点の選択UI |
| `PatternList` | 検索結果パターン一覧 |
| `MapCanvas` | react-konva ベースのマップキャンバス |
| `ZoneOverlay` | 収縮候補地（12ゾーン）の円形マーカー |
| `PatternLayer` | パターンの線・円を色分け描画 |
| `ShrinkOverlay` | 選択スロットの収縮エリア外を暗化 |

### データフロー

```
useMasterData()  → ボス・地変・開始地点・収縮ゾーンをAPI取得（初回）
usePatterns()    → ボス＋開始地点確定時にパターン検索
ConditionPanel   → 検索条件を state に反映
PatternList      → パターン選択 → PatternLayer / ShrinkOverlay に反映
MapCanvas        → ZoneOverlay / PatternLayer / ShrinkOverlay を子に持つ
```

```
※ スマホはサイドパネルがボトムシートに変化
```

### 収縮の仕様

ゲームの収縮メカニクムに基づき、第1次・第2次で管理するデータの種別が異なる。

| 収縮段階 | 概要 | 選択対象 | データ型 |
|---------|------|---------|---------|
| 第1次収縮 | 12ゾーンのいずれかに収縮（Day1・Day2ともに同じ12ゾーンを使用） | 収縮候補地（円形ゾーン） | `ShrinkZone` |
| 第2次収縮 | 第1次収縮ゾーン内のある1点にさらに収縮 | 第二収縮地点（座標点） | `SecondShrinkPoint` |

### スロット定義

| スロットキー | 表示名 | 選択対象 | 備考 |
|-------------|--------|---------|------|
| `1-1` | Day1 第1次収縮 | `ShrinkZone`（12ゾーンから選択） | 円形の収縮エリア |
| `1-2` | Day1 第2次収縮 | `SecondShrinkPoint`（座標点） | 第1次ゾーン内の特定地点 |
| `2-1` | Day2 第1次収縮 | `ShrinkZone`（12ゾーンから選択） | Day1と同じゾーン定義を使用 |
| `2-2` | Day2 第2次収縮 | `SecondShrinkPoint`（座標点） | 第1次ゾーン内の特定地点 |

> **実装状況（未対応）:** 現在の記録フォームは4スロットすべてで `ShrinkZone` から選択させている。
> phase 2（1-2・2-2）は `SecondShrinkPoint` の選択UIに変更が必要。

### 機能

| 機能 | 詳細 |
|------|------|
| 条件選択 | ボス・地変・開始地点をセレクトボックスで指定 |
| スロット入力 | マップ上のゾーン・地点タップで収縮先を入力 |
| 自動スロット移動 | ゾーン入力後に次の未入力スロットへ自動移動 |
| 開始地点表示 | 選択した開始地点をマップ上にアイコン表示 |
| 拠点候補地表示 | 開始地点選択後に拠点候補地を表示・タイプ割り当て可能 |
| Day切替 | Day1/Day2 ボタンで表示する日を切り替え（サイドパネル・マップ上ボタンの2か所） |
| 収縮表示トグル | 収縮候補地マーカー（ZoneOverlay）とエリア暗化（ShrinkOverlay）の同時 ON/OFF 切り替え |
| 自動保存 | フォーム内容を localStorage に 5秒間隔で自動保存（ページ離脱対策） |
| 記録送信 | 最低1スロット入力後に API へ送信可能。送信成功後 3秒でメイン画面へ遷移 |
| リセット | フォームと localStorage をクリア |

### 使用コンポーネント

| コンポーネント | 役割 |
|----------------|------|
| `RecordForm` | 条件選択・スロット・備考・送信ボタン |
| `MapCanvas` | マップキャンバス |
| `ZoneOverlay` | 収縮候補地（12ゾーン）の表示・タップ選択 |
| `SpawnPointMarkers` | 開始地点アイコン表示 |
| `BasePointMarkers` | 拠点候補地表示・拠点タイプ割り当て |
| `ShrinkOverlay` | アクティブスロットの収縮エリア外を暗化 |

### データフロー

```
usePlayRecord()      → フォーム状態管理・localStorage 自動保存・API送信
useMasterData()      → ボス・地変・開始地点・ゾーンをAPI取得
RecordForm           → フォーム操作 → usePlayRecord の setter を呼び出し
ZoneOverlay クリック → setEntry(activeSlot, zoneId) → 次のスロットへ自動移動
送信成功             → localStorage クリア → 3秒後に / へ遷移
```

#### 攻撃倍率
| 項目 | 説明 |

| 魔術攻撃倍率 | 魔術ダメージへの乗算倍率 |

- 例: `1.20 × 1.15 × 1.10 = 1.52倍`

### データフロー

```
useBuildSimulator()  → 選択状態（遺物4枠・祝福3枠）を管理
useRelicMaster()     → 遺物マスタをAPI取得（初回のみ）
useBlessingMaster()  → 祝福マスタをAPI取得（初回のみ）

RelicSlot クリック   → RelicSelectModal を開く
RelicSelectModal     → 遺物選択 → useBuildSimulator.setRelic(slot, relic)

計算ロジック（純粋関数）:
  calcAttackMultipliers(relics, blessings) → 攻撃倍率オブジェクト
  calcDamageCutRates(relics, blessings)   → カット率オブジェクト
  calcSetBonuses(relics)                  → 発動中セットボーナス一覧
  calcTotalMultiplier(multipliers)        → 累積倍率

URL共有:
  状態 → JSON → Base64 → クエリパラメータ ?b=xxxxx
  クエリパラメータ → Base64 → JSON → 初期状態に復元
```

### 必要なマスタデータ（新規追加）

| テーブル（仮） | 概要 |
|--------------|------|
| `relics` | 遺物マスタ（名前・タイプ・効果リスト） |
| `relic_effects` | 遺物の付帯効果（効果種別・値・条件） |
| `relic_set_bonuses` | タイプ別セットボーナス定義 |
| `blessings` | 祝福マスタ（名前・効果リスト） |

> **実装前確認事項:**
> - 遺物・祝福のマスタデータ仕様（効果の種別・数値の確認）
> - セットボーナスの発動条件詳細
> - 倍率の乗算・加算の優先ルール（倍率同士は乗算か加算か）
> - 遺物の入手条件・解放フラグの管理要否

|----------------|------|
| `MapCanvas` | マップキャンバス・クリック座標取得 |
| `AdminOverlay` | 登録済みマーカー・編集プレビュー表示 |
| `SpawnPointForm` | 開始地点の座標・名前入力フォーム |
| `ShrinkZoneForm` | 収縮候補地の座標・半径・名前入力フォーム |
| `SecondShrinkPointForm` | 第二収縮地点の座標・名前入力フォーム |

### データフロー

```
マップクリック         → clickedPosition に座標をセット → フォームに初期値反映
SpawnPointForm 保存    → adminCreateSpawnPoint / adminUpdateSpawnPoint
SpawnPointForm 削除    → adminDeleteSpawnPoint
ShrinkZoneForm 保存    → adminCreateShrinkZone / adminUpdateShrinkZone
ShrinkZoneForm 削除    → adminDeleteShrinkZone
SecondShrinkPointForm  → adminCreate/Update/DeleteSecondShrinkPoint
拠点候補地モードクリック → adminCreateBasePoint（フォームなしで即登録）
```

## 共通仕様

### レスポンシブ対応

| ブレークポイント | レイアウト |

| PC（md以上） | 左サイドパネル + 右マップエリアの2カラム |

### マップキャンバス共通仕様

| 項目 | 仕様 |
|------|------|
| 描画ライブラリ | react-konva（canvas 描画） |

| ズーム | マウスホイール：0.3倍〜3倍 |
| パン | ドラッグで移動 |

| 座標系 | マップ画像基準（1024×1024 px） |
