# エルデンリング ナイトレイン マップ収縮予測Webアプリ 要件定義書

**バージョン**: 3.0
**作成日**: 2026-03-16
**ステータス**: ドラフト

---

## 1. 概要

### 1.1 目的

エルデンリング ナイトレインのプレイ中にマップ収縮（夜の雨）の実績データをリアルタイム入力し、
蓄積されたデータを「ボス × 開始地点 × 地変」の組み合わせで検索・表示することで、
2回目以降の同条件プレイを有利に進める支援ツール。

### 1.2 基本コンセプト

```
【初回プレイ時】
  ボス・地変・開始地点を選択
  → 過去データなし
  → プレイしながら収縮先を入力 → DBに記録

【2回目以降（同じ条件）】
  ボス・地変・開始地点を選択
  → 過去に記録されたパターンを全件表示（複数あればすべて表示）
  → プレイ後に今回のデータを追記
```

**予測はアルゴリズムで計算しない。実プレイデータそのものが答え。**

### 1.3 対象ユーザー

- エルデンリング ナイトレインをプレイする全プレイヤー（初心者〜上級者）
- プレイ中にスマホで参照・入力することを想定

## 2. ゲームメカニクス（前提知識）

### 2.1 ゲーム基本構造

```
【1セッションの流れ】
1日目（昼） → 1日目（夜・中ボス） → 2日目（昼） → 2日目（夜・中ボス） → 3日目（夜の王戦）
```

- 1〜3人のCO-OPローグライク
- 3日目は専用ステージ（メインマップを使用しない）

### 2.2 マップ収縮（夜の雨）の仕組み

1日目・2日目の昼フェーズで2段階の収縮が発生する。

| 段階 | 開始タイミング | 所要時間 | 完了タイミング |
|------|--------------|---------|--------------|
| 第1次収縮 | 約4分30秒後 | 約3分 | 約7分40秒後 |
| 第2次収縮 | 約11分10秒後 | 約3分 | 約14分10秒後 |
| 夜ボス出現 | 約16分10秒後 | — | — |

**収縮先の決定ルール**
- 収縮先の候補地は全12ヶ所
- 1日目と2日目の収縮先は一定距離以上離れた場所に設定される
- 地変が発生中の場合、2日目の収縮先は地変エリア方向に引き寄せられる
- 第2次収縮完了時に「巨大な木の幻影」で視覚的に確認可能

### 2.3 マップ構造

**固定配置（毎回同じ位置）**

| 拠点名 | 概要 |
|--------|------|
| 祝福 | レベルアップ地点 |
| 霊鷹の止まり木 | 高速移動地点 |
| 霊脈 | 回復地点 |
| 坑道の入口 | 鍛石【2】確定入手 |
| 封牢 | 虜囚が封じられた牢 |
| 砦（中央砦） | 3パターンの敵・赤目ボス |

**ランダム配置（毎回変わる）**

| 種別 | 拠点名 |
|------|--------|
| 大拠点 | 小砦、大教会、大野営地、遺跡 |
| 小拠点 | 教会、魔術師塔、村、野営地 |

**開始地点**
- 小拠点（野営地または教会）の近くに出現
- 各プレイ開始時の近隣には必ず野営地か教会が配置される

### 2.4 夜の王（ボス）一覧

| ボス名 | 弱点属性 | 解放条件 | DLC |
|--------|---------|---------|-----|
| 三つ首の獣（グラディウス） | 聖 | 最初から選択可能 | — |

| 知性の蟲（グノスター） | 炎 | グラディウス撃破後 | — |

| 霧の裂け目（カリゴ） | 炎 | グラディウス撃破後 | — |

## 3. ユーザーフロー

### 3.1 プレイ開始時（条件選択）

```
1. ボスを選択（10体から）
2. 地変を選択（なし or 5種類から）
3. 開始地点をマップ上でタップ or 候補リストから選択
4. 「パターンを確認」ボタン
   → 過去データあり: 記録済みパターンを全件マップに表示
   → 過去データなし: 「まだデータがありません。今回記録しましょう」
```

### 3.2 プレイ中（リアルタイム入力）

```
1日目 第1次収縮完了後（約7分40秒）
  → マップ上の収縮先をタップして記録

1日目 第2次収縮完了後（約14分10秒）
  → 同様に記録

2日目も同様に繰り返す

プレイ終了後
  → 「このプレイを記録する」ボタンで確定保存
  → 備考（任意）を入力して送信
```

### 3.3 パターン表示

```
過去データが複数ある場合:
  ┌─────────────────────────────────┐
  │ パターン1（3回記録）              │
  │  1日目: 北砦付近                 │
  │  2日目: 南の教会跡               │
  ├─────────────────────────────────┤
  │ パターン2（1回記録）              │
  │  1日目: 中央湖畔                 │
  │  2日目: 東の遺跡                 │
  └─────────────────────────────────┘
  → マップ上にすべてのパターンを色分けして表示
  → パターンをタップすると該当パターンをハイライト
```

## 4. 機能要件

### 4.1 コア機能

#### F1: マップ表示
- リムベルドのマップ画像をキャンバス上に表示
- 固定拠点を画像アイコンでオーバーレイ表示（拠点種別ごとに異なるアイコン）
- 収縮候補12ヶ所の位置を薄く表示（選択前）

#### F2: 条件選択
- ボス選択（10体）— ボスの画像サムネイル付きで表示
- 地変選択（なし or 5種類）— 地変の画像サムネイル付きで表示
- 開始地点選択（マップタップ or リストから）

#### F3: 過去パターン表示
- 「ボス × 開始地点 × 地変」の組み合わせで過去データを検索
- 一致するパターンを全件マップ上に色分けして表示
- パターンごとに記録回数・最終記録日を表示

#### F4: プレイ中入力
- 1日目・2日目それぞれの収縮先をマップ上でタップ入力
- タイムライン表示（次の収縮まで何分か）
- 入力途中でも一時保存可能

#### F5: プレイ記録保存
- 入力した収縮先を確定してDBに保存
- 備考（任意）を添付可能
- 保存後すぐにパターン一覧に反映

#### F6: パターン統計表示
- 同条件のパターンが複数ある場合、収縮先ごとの出現回数を表示
- 「3回中2回は北砦付近」のような形で表示

### 4.2 将来的な拡張機能（v2以降）

| # | 機能 | 概要 |
|---|------|------|
| E1 | ユーザー認証 | 自分の記録と全体の記録を分けて管理 |
| E2 | 深き夜モード | 深度別の収縮パターン記録 |
| E3 | エクスポート | 自分の記録データをCSVエクスポート |
| E4 | 管理画面 | 誤記録の削除・マスタデータ編集 |

## 5. 非機能要件

| # | 要件 | 詳細 |
|---|------|------|
| NF1 | レスポンシブ | PC・スマホ・タブレット対応（プレイ中に片手で操作） |
| NF2 | 高速表示 | 条件選択後のパターン表示は1秒以内 |
| NF3 | オフライン対応 | PWA対応（ゲーム中のネット不安定環境でも動作） |
| NF4 | コンテナ化 | Docker Composeで一発起動 |
| NF5 | アクセシビリティ | 色覚多様性を考慮したカラーパレット（パターン色分けに注意） |
| NF6 | データ整合性 | 誤入力は備考で補足し削除はしない方針 |
