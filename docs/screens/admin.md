# 画面: マスタの管理

マップを押して、開始地点、収縮候補地、第二収縮地点、拠点候補地の座標を登録し、直す画面である。

| 項目 | 内容 |
|---|---|
| パス | `/admin` |
| 使う人 | 管理者 |
| 骨組みと遷移 | [画面設計: 画面の一覧と遷移](../design/screens.md) の 3.7 |

## 対応する設計

| 文書 | この画面について決めていること |
|---|---|
| [機能設計: マスタの管理](../design/master-admin.md) | 管理用の鍵の入力、登録するものの種類、入力の検証、非表示にする操作 |

## 見た目の試作

枠の中は、押したり切り替えたりできる。
保存はされない。
マップ画像と開始地点のアイコンは、アプリと同じ `frontend/public` の画像を使っている。

### 広い画面

収縮候補地「最北」を直している状態である。
直している円を青の破線で出している。行を消すボタンはなく、「非表示にする」で、プレイヤーの画面と新しい記録の入力から外す。
ヘッダーにはほかの画面への入口を出さず、`ADMIN` の印と「鍵を消す」だけを出す。
鍵のないときに出す入力の欄は、[共通の部品と状態](common.md) の試作の「管理用の鍵」にある。
