## 試作の決まり

- 試作の値(色、書体、余白)は、[画面の共通仕様](../design/common-frontend.md) の値と同じにする。試作と共通仕様が食い違ったら、共通仕様が正しい。
- 試作は `mock.css` と `mock.js` を共有する。画面ごとに CSS を書かない。
- 試作は、見た目と並びを決めるためのものである。項目と動きの正本は、機能の設計の文書である。
- 実装の画面を試作と見比べるときは、広い画面を幅 1,100px、狭い画面を幅 390px で開く。
